# Выполнение лабораторных работ по дисциплине "Моделирование систем" за 5 семестр
___
### Структура
Каждая лабораторная работа имеет свою директорию, в которой расположены:
* Исходный текст задания
* Задание выполненое в Scilab (опиционально отчет...)
* Задания выполненое по средствам Python (используется версяи 3.14.4)
* Задания выполненое по средствам JavaScript

Структура файлов
```bash
.
├── laboratory_work_num_1
│   ├── LR_1_scilab.docx
│   ├── LR_1_scilab_result.docx
│   ├── LR_1_javascript.js
│   └── LR_1_python.py
...
├── laboratory_work_num_N
│   ├── LR_N_scilab.docx
│   ├── LR_N_scilab_result.docx
│   ├── LR_N_javascript.js
│   └── LR_N_python.py
└── README.md
```
